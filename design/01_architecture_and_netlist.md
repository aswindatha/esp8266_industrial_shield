# Part 1 — Architecture, Block Diagram and Interconnection Table

> **Superseded in part.** The layout-phase ECOs in [`05_layout_execution_plan.md`](05_layout_execution_plan.md) §0 change: J2 ↔ J27 roles, U12/C20 added, RN7/RN8 added, H1/H2/TP1–TP3 removed, GND split into `GND`/`GND_FIELD`, D1 → SMAJ15A, D2 → SS54. The netlist files in this folder are already regenerated; the tables below reflect the pre-ECO state and are kept for the design rationale.

**Project:** ESP8266 8× 12 V unidirectional motor + 16× opto-isolated field input controller
**Board:** 170 × 100 mm, 2 layer, 1.6 mm FR-4, 1 oz Cu, HASL-LF
**Netlist source of truth:** [`NETLIST.csv`](NETLIST.csv) (451 pin rows, machine readable) and [`NET_SUMMARY.md`](NET_SUMMARY.md) (97 nets, per-net pin list). Both are generated by `gen_netlist.py` — re-run it after any change and it will re-validate for floating pins.

## 1.2 Power tree and current budget

| Rail | Source | Load | Typical | Peak / worst case |
|---|---|---|---|---|
| +12V | J1 → F1 → D2 | 8 × motor 300 mA | 2.40 A | 3.20 A (stall) |
| | | 16 × opto LED (9 mA) | 0.14 A | 0.18 A @ 14.4 V |
| | | XL1509 input (η ≈ 0.80) | 0.26 A | 0.31 A |
| | | **total** | **2.80 A** | **3.7 A** |
| +5V | U1 buck, 2 A | AMS1117 input | 0.40 A | 0.45 A |
| | | HC-SR04 / JSN-SR04T | 0.015 A | 0.030 A |
| | | **total** | **0.42 A** | **0.48 A** |
| +3V3 | U2 LDO, 1 A | ESP-12F | 0.080 A | 0.35 A (TX burst) |
| | | U4 + U5 quiescent | 0.002 A | 0.002 A |
| | | 16 × 10k opto pull-up | 0.005 A | 0.005 A |
| | | **total** | **0.087 A** | **0.36 A** |

**Dissipation audit**

| Part | Worst case | Package limit | Verdict |
|---|---|---|---|
| D2 SS34 (series drop 0.5 V @ 3 A) | 1.5 W | SMA θJA ≈ 75 °C/W | **needs copper pour or SS54** |
| U1 XL1509 (η 0.8, 2.5 W out) | 0.6 W | SOIC-8, 40 V | OK |
| U2 AMS1117 (1.7 V × 0.36 A) | 0.61 W | SOT-223 θJA ≈ 60 °C/W | OK with 200 mm² tab pour |
| U6 / U7 ULN2803 (4 ch each, VCE ≈ 1.0 V) | 1.2 W each | SOIC-18W θJA ≈ 58 °C/W | **Tj ≈ 122 °C at 50 °C ambient — see Part 4** |
| R11-R26 1.2 k | 0.145 W @ 14.4 V | 1206 = 0.25 W | OK in 1206, **not** in 0805 |

Buck design check, U1: D = 5/12 = 0.417, ΔI = (12−5)·5/(12·150 k·33 µ) = **0.59 A p‑p** (30 % of 2 A, 118 % of the 0.5 A actual load → converter runs in DCM at light load; output stays regulated, ripple rises to ≈ 40 mV, acceptable). Average diode current D3 = IOUT·(1−D) = 0.35 A.

## 1.3 ESP8266 pin allocation

| Module pad | GPIO | Net | Function | Constraint / note |
|---|---|---|---|---|
| 1 | — | `RST` | Reset, active low | 10 k pull-up + SW2 + 100 nF max |
| 2 | ADC | `ADC` | 0–1.0 V analog | **never** > 1.0 V; test point only |
| 3 | — | `EN` | Chip enable | 10 k pull-up + 100 nF RC (1 ms) |
| 4 | 16 | `GPIO16` | Spare / deep-sleep wake | no PWM, no interrupt, no pull-up |
| 5 | 14 | `ECHO` | HC-SR04 echo in | 1 k/2 k divider, 3.33 V |
| 6 | 12 | `TRIG` | HC-SR04 trigger out | **strapping pin (MTDI)** — 10 k pull-down R6 |
| 7 | 13 | `GPIO13` | Spare / HSPI MOSI | test point |
| 8 | — | `+3V3` | Supply | 100 nF + 10 µF within 3 mm |
| 9–14 | — | `GND` | 6 × bottom thermal pads | solder + 4 vias each |
| 15 | — | `GND` | Side ground | — |
| 16 | 15 | `GPIO15` | **strap: must be LOW** | 10 k pull-down R4 |
| 17 | 2 | `GPIO2` | **strap: must be HIGH** | 10 k pull-up R5 |
| 18 | 0 | `GPIO0` | **strap: boot mode** | 10 k pull-up R3 + SW1 to GND |
| 19 | 5 | `SCL` | I²C clock | 4.7 k to 3V3 |
| 20 | 4 | `SDA` | I²C data | 4.7 k to 3V3 |
| 21 | 3 | `RXD0` | UART0 RX | 3.3 V logic only |
| 22 | 1 | `TXD0` | UART0 TX | boot log at 74880 Bd |

**KiCad symbol caveat.** `RF_Module:ESP-12E` numbers the six bottom thermal pads **9–14** and therefore shifts the right-hand pads to **15–22**. The table above uses that KiCad numbering. If you build a custom 16-pin symbol instead, the physical mapping is: left edge top→bottom = RST, ADC, EN, GPIO16, GPIO14, GPIO12, GPIO13, VCC; right edge bottom→top = GND, GPIO15, GPIO2, GPIO0, GPIO5, GPIO4, RXD, TXD. **Verify pin 1 by hovering it in the schematic before wiring** — it is the pad nearest the antenna on the left edge.

**Expander map**

| Device | 7-bit addr | Bank A | Bank B |
|---|---|---|---|
| U4 MCP23017 | `0x20` (A2..A0 = 000) | GPA0-7 = `M1_DRV`…`M8_DRV` (to ULN inputs) | GPB0-7 = `EXP_B0..B7` → H1 spare header |
| U5 MCP23017 | `0x21` (A2..A0 = 001) | GPA0-7 = `OPT1_COL`…`OPT8_COL` | GPB0-7 = `OPT9_COL`…`OPT16_COL` |

`U4.18` / `U5.18` (RESET) each get a 10 k pull-up; `INT` pins are left as no-connect test pads (polled design).

The collector/emitter pairing (16/15, 14/13, 12/11, 10/9) follows the standard quad-optocoupler layout — **confirm against the pin diagram of the exact part you buy before release**.

| 10 | U10 | 3 / 4 | 14 / 13 | J20 | R20 | D13 | U5 GPB1 |

| 12 | U10 | 7 / 8 | 10 / 9 | J22 | R22 | D15 | U5 GPB3 |

| 16 | U11 | 7 / 8 | 10 / 9 | J26 | R26 | D19 | U5 GPB7 |

Field chain per channel: `FLD_12V → LED anode → LED cathode → 1.2 k → terminal pin 2`, with `1N4148` anode on the LED-cathode node and cathode on `FLD_12V` (antiparallel, clamps LED reverse to 0.7 V while the 1.2 k still limits fault current). Logic chain: collector → 10 k pull-up array → MCP23017 input; emitter → GND.

**Logic polarity: field line active (pulled to 0 V) ⇒ LED on ⇒ transistor on ⇒ expander bit reads `0`.** Invert in firmware.
